# XTB Manual Plan

XTB fica em modo manual/assistido para FIRE, ETFs, accoes, relatorios e validacao fiscal Portugal.

Permitido:

- Relatorios de apoio.
- Watchlists manuais.
- Preparacao de notas para decisao humana.
- Validacao fiscal assistida.

Proibido:

- Automacao de clique.
- Robo de envio de ordens.
- Leitura de secrets reais.
- Execucao sem operador humano.
