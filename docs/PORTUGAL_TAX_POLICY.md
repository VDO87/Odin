# Portugal Tax Policy

Este projecto considera Portugal como contexto fiscal principal, mas nao presta aconselhamento fiscal.

Regras:

- Relatorios fiscais sao auxiliares e requerem revisao humana.
- Dados de XTB, ETFs, accoes e FIRE devem ser tratados como material de apoio.
- O sistema deve distinguir ganhos realizados, dividendos, custos, impostos retidos e notas de auditoria.
- Qualquer declaracao fiscal deve ser validada fora do sistema antes de submissao.

## A4 - Reserva Fiscal Conservadora

- Mais-valias: reserva interna de 30%.
- Rendimentos de capital: reserva interna de 30%.
- Cenarios de maior incerteza/rendimento elevado: reserva interna de 53%.
- Apenas lucro realizado conta para calculos internos.
- Excesso so deve ser libertado depois de IRS fechado e revisto.
