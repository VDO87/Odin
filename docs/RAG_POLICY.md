# RAG Policy

RAG serve para recuperacao de contexto e apoio a relatorios.

Regras:

- Fontes devem ser registadas e auditaveis.
- Dados sensiveis ou secrets nao entram no indice.
- Respostas devem indicar incerteza quando a fonte nao for suficiente.
- RAG nao decide ordens.
- RAG nao substitui Risk, Treasury ou validacao humana.
