# Odin Dashboard Builder

- Mostrar estado de Core, Risk, Treasury e Hermes separadamente.
- Expor bloqueios de forma clara.
- Nunca mostrar "pronto para real" se Core ou Risk estiver bloqueado.
- Priorizar auditoria, logs e decisao assistida.
- Nao criar comandos de execucao real.
